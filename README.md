Проект выполнен как 4 вариант задания.
В приложении существуют 3 роли - ADMIN, USER, EDITOR.
В приложении можно создавать новости(роль ADMIN или EDITOR), можно читать и комментировать новости , ставить закладки по темам.
Функционал приложения также зависит от роли. ADMIN имеет полный доступ к редактированию и удалению, EDITOR - может работать только со своими новостями, USER- может только читать, комментировать , фильтровать по темам .

При первом подключении к новой базе project postgres 5432 ,приложение само создает схему, таблицы для базы данных , а также вносит в базу запись с новым редактором.
api.base-url=http://localhost:24110/api/v1.0/
Запуск приложения в LessonRestApplication.

На странице login происходит аутентификация пользователя с ролью ADMIN или USER.Здесь же можно создать нового пользователя с ролью USER.Для входа как ADMIN - логин- admin , пароль-admin , для пользователя USER - логин- user , пароль-user или данные после регистрации.
Для входа или регистрации как EDITOR ,нужно поставить галочку в "я редактор" и перейти в форму аутентификации редактора или регистрации нового редактора. Чтобы создать нового редактора нужно на вкладке "вход редактора" нажать ссылку "создание нового редактора",
откроется страница EDITORS , на этой странице нажать кнопку "CREATE NEW EDITOR", заполнить форму.
